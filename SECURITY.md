# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/tarikalim/Westron/security/advisories/new),
or send a private message to [@tarikalim](https://github.com/tarikalim). Include the steps to
reproduce it and the version you used. You will get an answer within a week.

## Scope

Westron runs locally and opens no network port. It reads the files you hand it and writes the
results next to them; files are never uploaded. Conversions that need FFmpeg, LibreOffice, Pandoc,
calibre or Ghostscript run the copy installed on your Mac. The global drag gesture asks for the
Accessibility permission and reads only the modifier keys and the mouse while you drag.
